# Análisis de viajes de Ecobici en Buenos Aires

## Descripción
Este proyecto tiene como objetivo analizar los viajes realizados mediante el sistema Ecobici en la Ciudad Autónoma de Buenos Aires, utilizando Python.

## Pregunta de análisis
¿En qué horarios se realizan más viajes de Ecobici y cuáles son las estaciones más utilizadas?

## Objetivos
- Identificar los horarios de mayor demanda.
- Determinar las estaciones más utilizadas.
- Analizar la duración de los viajes.

## Fuente de datos
Datos abiertos del Gobierno de la Ciudad de Buenos Aires.
https://data.buenosaires.gob.ar/dataset/bicicletas-publicas
